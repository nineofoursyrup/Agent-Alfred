## 刻意偏离与公共配方建议

1. 原稿平均耗时、p95、闸门比例、导航角标、自动执行动画与 Syrup 专有节点没有迁入产品。原稿五卡变三卡，只显示已有真实事实；费用三态仍能看到分项和缺口。
2. 来源控件、观察时间、覆盖说明及完整身份使页面高于原稿；指标卡的自然高度随文字不同。ADR-0047 的来源边界和可验证事实优先于压缩为演示卡的固定高度。
3. 历史最近运行 API 明确剔除 `prompt_preview`（`gateway/web/shared_reads.py`）。本票的可省略预览仍为既有用途摘要，不新增读取、不伪造消息预览；结局与记录等关键事实不能省略。
4. 390／320px 保留现有 Alfred 窄屏壳层，原稿截图不强行适配。架构保留较宽图面，用局部键盘滚动读取；不让整页横向滚动。
5. #124 合并前页头、英文眉标、副标题、导航和 `<title>` 仍为旧壳层。这是分工下的预期截图，不属于 V04 漏改。

建议后续公共层增加 `sy-metric-grid` 与 148px 最小卡宽 token，支持 `auto-fit minmax` 和不足最小宽度时的安全收缩；V04 临时用现有间距 token 派生 148px，没有修改冻结层。也可提供 14.5px 节点标题 token 及静态 SVG 的节点／分区／实线／虚线／箭头配方及具名局部滚动容器样式；可访问名称、聚焦和静态语义继续由页面负责。现有面板、指标、行、芯片和语义色配方足够，本票没有另造相同公共定义。
