# V04 本地范围复核

固定候选以 `candidate-source.json` 的三个 SHA-256 与完整差异为准；本次是 implement 收尾的本地自审，不是独立评审。

## Standards

参照用户当前文件归属／并行约束、全局 AGENTS.md、RECIPES-v1、ADR-0045～0049 与 code-review 的 smell baseline。只改本页的三份产品／测试文件，证据是明确授权的新增文件。CSS 选择器全部受 `.overview` 限定，无字面色值或尺寸、`:root`、公共 sy- 定义、style 写入、远程资源或 `.gitattributes` 变更。公共指标／面板／行配方复用；页头、导航和 title 未改。未发现应阻塞交付的文档标准违背或新增 smell。

## Spec

只读取既有三个来源。期间计数与费用保持同份观察，当前记忆独立修订，最近历史与当前槽分开，过期／失效／断连／刷新状态及 exact／estimated／unknown 原合同继续适用。架构可访问名称原样保留，新增具名可聚焦滚动 region，实线／虚线箭头表达已有关系，无状态绑定或执行动画。TURNS 行仅用途预览可截断，结局、记录、完整冲突身份及来源事实可见。测试只修改几何起始视口与容器断点，没有重试、延长超时或放宽断言。四视口的独立补充审计已验证局部滚动、3px 焦点和状态可读。

Standards: 0 项；Spec: 0 项；各轴无阻塞问题。完整门禁结果另以实际原流为准，本报告不预判仍运行的门禁。
