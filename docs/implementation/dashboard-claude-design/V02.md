### 刻意保留的差异

- Alfred 品牌、十个中文导航名和既有分组替代原稿演示名称；没有模型演示行、数字角标、库路径／大小或语言切换。品牌状态和地址均来自已有事实。
- 页头眉标用页面英文名大写，副标题说明 Alfred 实际功能；状态文字及已有「打开主对话」入口保留，不搬 `live · turn #48`。
- 宽屏 `#shell-toolbar`（含「打开主对话」和状态胶囊）位于 `#page` 滚动容器内的 `#page-header`，页面向下滚动后会随页头离开视口。改版前 toolbar 固定在 `#page` 上方；这是本次改版的壳层行为变化。Spec-1 评审中用户明确选择 (a)，保留当前行为并记录依据：归档原稿 `Syrup Dashboard.dc.html:88–99` 的 `header` 是 `overflow-y:auto` 的 `main` 的直接子节点，没有 sticky／fixed 定位，随 main 内容一起滚动。窄屏 toolbar 仍位于 `#workspace`、`#page` 之前；原面板开关、遮罩、焦点归还和离页确认保持原行为。本次没有实现宽屏常驻入口，也没有放宽现有断言。
- 原稿预览实际外宽为导航 233px／aside 321px（内容宽加边线），有效 h1 为 32px、品牌为 16px（原稿 `font:... inherit` 未成为有效字号）。产品按 #122／#124 和 token 合同使用外宽 232／320px、h1 27px、品牌 19px；因此页头约 119.84px，原稿约 130.5px。
- 原有标题聚焦仍呈现 3px 焦点轮廓；总览同路由点击的截图未产生导航聚焦，另九页截图有标题轮廓。原稿缺少焦点样式，此差异按 ADR-0049 保留。
- 原稿窄屏没有 Alfred 的面板行为。产品保留原工具栏、导航抽屉、遮罩及状态迁移，只把页头文字重排。各页业务内容／MainBar 对话样式仍由相邻票负责。

局部尺寸首轮使用字面值，第一次评审后曾改为冻结 token 的 `calc()` 推导；该历史记录保留。本次 Std-1 明确要求角色值不从字号／圆角换算，故改为单处定义 `--shell-rule:1px`、`--shell-nav-gap:2px`、`--shell-group-spacing:2.2px`、`--shell-eyebrow-spacing:2.6px`、`--shell-subtitle-width:660px`，并为地址间距、状态胶囊 padding、标题 margin、导航水平 padding、窄屏 toolbar padding 使用壳层角色 token。`#page` 的 padding 与页头的负外边距共享同一组变量：宽屏 28px，窄屏纵向 20px／横向既有 `--gap-large`（16px）。这取代此前的字号／圆角间距推导，不改变冻结公共层。
