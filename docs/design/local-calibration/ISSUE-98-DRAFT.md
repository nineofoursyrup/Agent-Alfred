## R-03 本地信任与系统边界

机主、其认可的 macOS 和可信宿主代码是可信基。宿主可合并 Controller、Authority、Dispatch、决定源读取与审计；不要求额外管理员、远程服务、三账户、Region、IAM/KMS/Lambda、DynamoDB、S3 Object Lock 或云网络。

受限 runner 使用原生 App Sandbox launcher 和捆绑 Python helper，固定安装字节、签名、entitlements、依赖、启动环境与本案状态。无 network client/server entitlement，通过窄管道/限定 FD IPC 请求宿主执行固定操作。不给 provider 凭据、机主环境、任意网络/shell/UI工具、批准/预算/审计写权、完整材料包或管理权。子进程继承限制；实际 Keychain/文件权限须验证，不能笼统声称沙箱禁止所有 Keychain/exec/系统文件。

宿主独占 provider secret；仅完成当次来源/撤回/阶段/候选/投影/预算/见证校验后取用。宿主固定 HTTPS 端点、TLS 校验、零重试/重定向/ambient proxy。runner 无法通过 IPC 改 URL/header/role/principal/path/SQL、重放或提权。身份由实际启动/IPC绑定确定，不采纳请求正文的身份字符串。

明示变化：独立性仅相对受限 runner；不防机主/root或可信宿主失陷，不承诺管理员不可改审计/共同回滚或第三方不可否认性。宿主固定出口是可信代码保证，不是失陷宿主仍受域名级OS封锁。普通Dashboard无鉴权合同不变，也不是批准源。实际系统隔离证据由 #105 提供，当前 unrestricted Codex 会话不算受限 runner。

## R-06 阶段、检查点和原时钟

同一job固定顺序：预检与具体运行事件 → 明确激活 → **18裁判检验 → 18独立盲复核及本地对照 → 机主质量检查点 → 30案产品首次采样 → 最多30原判 → 最多30盲复核及本地对照 → 停新派发/结算/完整摘要**。

诊断结束核验全部36个Attempt与结果/盲评原件，产品样本数仍0。已确认禁止项漏判使该judge配置失败；未解决争议/证据缺口不放行，18题全对亦不自动继续。checkpoint绑定本job、原run事件、精确诊断摘要、逐项裁决、当前余量，不能授权未来产品质量或刷新预算。没有确认、撤回、失联或超时即停止。

原grant激活时固定10800秒，人工等待、阶段切换、重启、证据版本都消耗原时间。`finish`不可逆，不新起grant绕过原额度；尚无产品结果时不要求完整校准批准，避免循环前置。新诊断事件不得伪装完整产品摘要。
