## 要验收什么

在用户确认本地信任合同、本地适配完成且具体本机操作获授权后，对**最终真实 macOS 安装物**验证：机主可信宿主与受限 runner 分离、真实机主批准来源、凭据独占、runner 出口拒绝、持久账/审计、容量、停止与恢复。无需 AWS 账户、Region、远程审批服务或额外管理员。

机主、macOS与可信宿主纳入可信基；runner及其模型输入不可信。不防机主/root修改程序、批准、磁盘或直接使用凭据；本地见证不承诺第三方不可否认、管理员不可删、跨管理域抗共同回滚。宿主固定供应商URL由其可信代码强制，不声称失陷宿主仍有OS域名封锁。这些是必须先批准的原保证变更。

本票不发送真实产品/judge请求。使用实际权限/进程/文件/SQLite与无价值测试secret、受控无计费端点验证系统边界；Mock可辅助证明状态机，不能替代OS拒绝与机主读回。测试secret能证明ACL配置方法；生产key配置后须确认同一访问策略和宿主身份，不能从sentinel直接推断任意既有key都已安全。

## 验收标准

- [ ] **AC1 — 实际主体与安装。** 记录本机OS/架构、机主主体、可信宿主、原生launcher、Python/helper实际身份、签名、entitlements和启动环境。runner不持管理员/通用UI/任意shell或环境凭据，子进程继承沙箱；确认App Sandbox实际生效。普通同UID双进程、两个目录、纯类型检查不是通过依据。没有worker network client/server entitlement；项目依赖无法在该边界运行时阻塞，不增加广泛例外掩盖。
- [ ] **AC2 — 真实机主来源。** LocalDecisionSource 的签发入口仅由受保护的机主界面和真实在场认证使用，runner只能读受限状态。正向用本次实际本地认证事件，验证主体、时间、nonce、精确对象、范围、撤回与重启再读；负向验JSON伪批、错对象、过期、重放、失联。沿用r7与三条争议范围，原消息ID/时刻缺失不伪造，原unknown不改PASS；承接事件不等于历史原事件已认证，更不授予付费运行。
- [ ] **AC3 — 精确候选与容量。** 绑定#107已交付机制及新本地增量最终候选，记录host/runner/解释器/标准库/native extensions/依赖/协议/entitlements加载字节和安装产物；不从agent可写路径导入。复用完整材料引用及576次最坏事件计划，验证真实本地SQLite/追加见证、完整原件、IPC/磁盘限制；容量测试保持synthetic/no-fee，不为压测调用模型。Ubuntu/macOS工程证据分别记录。
- [ ] **AC4 — 文件、凭据与权限拒绝。** 以实际runner及可继承子进程尝试读取provider sentinel/机主文件/金标/他案资料/签发材料，尝试修改ledger、见证、批准、预算、候选及启动权限；涵盖symlink、路径穿越、FD泄露和提权。Keychain按特定项目/宿主代码身份验证，不能笼统声称沙箱拒绝全部Keychain。runner环境和可达IPC/FD中没有provider secret、signer、SSH agent、宿主可写控制接口。机主从runner外读取策略和原始拒绝记录；超时与真实权限拒绝分开。
- [ ] **AC5 — 出口和 IPC。** 验证runner/子进程直接TCP/UDP、IPv4/IPv6、DNS、loopback、代理、继承socket、通用系统代发/本地端口均不形成旁路；先用授权无计费目标。限定FD/管道IPC绑定实际进程和job，拒绝任意URL/header/path/SQL/command、自报principal/role、越阶段、重放和超大帧。宿主固定TLS供应商端点，无自动重试/重定向/ambient proxy；canary故障验证不冒充实际供应商响应。实际出口策略/启动或凭据ACL改变后重验受影响边界。
- [ ] **AC6 — 停止、恢复与未知责任。** 在新测试库/授权对象上验证撤回在SEND_INTENT前后的竞态、发送可能已发生、丢响应、时间回退/休眠恢复、部分写入、源/见证失联、磁盘满、正常handoff、突然崩溃及清理失败。保留原起点、首次原因、全部原错误、不可逆停止、未决最坏负债；异常恢复不能重发、退款或重开旧grant。共同磁盘回滚不声称可被独立证明；无法核验即保持停止并展示证据局限。
- [ ] **AC7 — 留存、费用与清理。** 明确本地进程/文件/SQLite/审计存储的拥有者、输出范围、剩余资源、停止和只读检查方式。原证据不自动删除；另行授权删除时保存身份/摘要和不可复用标记。不要求AWS费用、Object Lock保留期或USD100/72h/30天示例；任何新增付费依赖另列报价授权。停止本机任务不等于供应商结算结束。
- [ ] **AC8 — 可复核证据与结论范围。** 生成最终候选绑定的权限/出口/故障原始结果和manifest，由机主在runner外读回。每项明确“实际本机实测 / 模拟协议 / NOT RUN”，记录失败及修复前后结果。本票PASS只代表已批准的本地信任合同；不代表原AWS三域通过、硬金额已验、运行grant已签、模型质量或v1发布通过。
