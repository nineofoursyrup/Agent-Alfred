## 第一轮：Q1–Q3

日期：2026-10-08。

用户在收到 Q1–Q3 后原文回复：

> 全按建议

当轮展示并确认的建议：

1. **Q1 Memory**：记忆内容在上，维护与统计在下；上方保留语义记忆、情景记忆、Skill 目录三标签，下方按业务分区展示维护信息并按需展开。未确认操作、遗忘待办、失败和待审批事项保留可见摘要及定位入口。Skill 只读；人格沿现有 `read_persona`／`update_persona` 主对话工具路径操作。
2. **Q2 Behaviour**：操作优先，消息分流与手动聚合为上下两个常驻业务区；每区先显示配置或请求表单及结果，路由统计属于分流区，两个只读流程图分别按需展开。
3. **Q3 Tools**：按真实来源分组的紧凑目录再进入单项明细；首层展示名称、简述、副作用及关键状态和阻止原因，明细承载完整身份、连接观测与授权编辑，保留逐项显式保存。调用记录沿既有入口进入 Ops，原型静态次数不进入产品。

对应 [DECISIONS.md 第一轮](DECISIONS.md)。此答复没有裁定当时尚未展示的详情位置、展开行为、统计图形或后续验收方案；这些在第二轮单独展示与确认。答复不表示已经实施产品或授权提交、推送及远端收尾。

## 第二轮：Q4–Q9

日期：2026-10-08。

用户在收到 Q4–Q9 后再次原文回复：

> 全按建议

当轮展示并确认的建议：

1. **Q4 Memory 详情与编辑**：中央单列列表加页内详情；列表正文最多三行，来源、保护与异常可见；详情读完整正文并编辑，新建表单从列表上方展开。宽窄屏顺序相同，代码与表格局部滚动。
2. **Q5 次级区块**：标题、状态摘要常驻，详情默认收起；失败、待处理、未保存、未核验和在途状态可见，用户点击定位并展开，后台不自动抢开。分页摘要标明范围，未核验不显示成无待办。
3. **Q6 流程图布局**：全宽图、选中节点详情、完整节点／边文字清单上下排列；保留缩放、平移、适应全图及文字入口，原始技术字段折叠，窄屏沿用。
4. **Q7 路由统计**：横向条形图配准确数表，按可比较版本组分别显示次数、百分比、分子与分母；覆盖与缺口另列，未知版本只列次数与缺口，零分母显示无可计算样本。
5. **Q8 Tools 分组与明细**：内置工具、集成来源、MCP 服务器分组，组内按名称稳定排序，允许多项就地展开；草稿、保存值和生效分开，收起后保留未保存／冲突提示，历史不可调用目录独立展示。
6. **Q9 页面输入**：仅隐藏或切换页内视图保留输入；会替换／清空编辑目标时先选择保留当前编辑或放弃后继续；刷新事实不覆盖草稿，已提交请求保持原对象与参数，沿用既有恢复范围。Memory 遗忘核验、隐藏和清除继续优先。

对应 [DECISIONS.md 第二轮](DECISIONS.md)。两轮确认只构成设计批准；产品实施、文档提交／推送和远端 resolution／关闭仍是不同动作。
