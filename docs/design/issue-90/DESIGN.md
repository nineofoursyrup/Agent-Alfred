## R01：摘要、长内容与折叠

依据：Q1–Q8、#86。

1. 记忆列表正文最多三行，明确提供完整详情入口；来源、保护、版本变化和异常状态不使用正文截断规则。Skill／工具简述可采用同类摘要，名称和辨识不同来源所需的信息须可读全。
2. 完整正文在页内详情按原有文本能力显示，不增加任意 HTML 执行或新的富文本格式。长代码、原始结构及表格在有名称、键盘可达的局部区域滚动；长标识换行，整页不横向溢出。
3. 新建记忆表单由列表上方按钮展开；显式编辑在所选记录详情内进行。宽窄屏保持同一阅读顺序，操作、标签与字段错误不因缩窄隐藏。
4. 次级区块标题、状态摘要常驻。失败、待处理、未保存、未核验、在途状态和必要原因在收起时仍可见，可定位到详细结果；已消除的状态按权威新事实更新，不以定时消失代替处理。
5. “无待办”只适用于已核验的明确范围。操作回执是本标签页范围，队列是当前页／筛选范围；未读、过期、部分分页与读取失败明确显示，不能把当前页长度当全局计数。没有全量数据时不新增装饰性总数。
6. 摘要采用相应业务协议允许展示的内容。Memory 离线或失效时，正文、主题、候选差异和镜像预览不能从摘要、标题或提示副本重新出现；保留无正文操作身份、状态及核验入口。
7. 首次进入按表中默认显示；当前页面内的展开状态保持到用户改变，异步完成、刷新和重连不主动展开或收起，也不夺焦点。实际离页／重载后的恢复依原页面及 #87，不额外持久保存全部展开状态或内容。
8. 点击定位入口才展开目标区并将焦点移至有效标题或动作；折叠前若焦点在即将隐藏的区域，归还对应展开控件。后台更新保持用户已有焦点与阅读位置。

## R02：输入、目标切换与异步完成

依据：Q9、#87 R03–R06、[ADR-0046](../../adr/0046-panel-visibility-preserves-page-lifecycle.md)。

| 操作 | 迁移后的行为 |
| --- | --- |
| 收起详情、打开其他次级视图、切 Memory 类别 | 当前页面内输入仍属原对象，未保存提示保持可达；不自动提交、不重新生成。只读视图继续遵守自身取消／失效规则 |
| 选择另一条记忆，且会替换当前编辑目标 | 有实质未保存内容时先选择「保留当前编辑／放弃后继续」；默认保留，Esc 取消替换。取消后目标、输入、选择和位置不变 |
| 新建表单收起后再次展开 | 仍是当前页面的同一份输入；显式取消／重置若确实丢输入，也先按替换规则处理 |
| 检索、分页或读取当前值 | 不把旧选择伪装为新结果，也不隐式换编辑目标。可保留当前独立详情并标明它不在当前结果；若实现会丢失编辑，必须先经过相同守卫 |
| 刷新分流设置或授权当前值 | 更新服务端事实并比较草稿；没有修改的控件可随当前值更新，已有草稿保留其基线和冲突提示，不能以刷新偷偷接受新版本 |
| 点击保存／生成后继续编辑 | 原请求绑定点击时对象、版本、Session 与参数；回执不应用到新目标，也不能清掉提交后新增的输入。只有相符且未再修改的输入才能按原动作清理 |
| 点击其他路由、浏览器跨页返回／前进 | 由 #87 离页守卫处理：留在此页，或放弃未提交输入后离开；已提交动作不会因离页撤销或自动重发 |
| 刷新／关闭整个文档 | 沿用浏览器离开提示与已有恢复范围，不新增通用草稿库。Tools／聚合未提交表单不承诺跨刷新恢复；Memory 已有同操作恢复仍保留 |
| 记录删除、记忆修订、来源许可或范围版本变化 | 保护与业务失效优先；核验后清除被遗忘内容或失效授权选择，不让“保留输入”复活旧正文或授权新范围 |

守卫针对真实的数据丢失，不把查看说明、只读刷新或无变化字段都认作新修改。来源／范围确认继续绑定原身份与修订，不能因界面重绘把旧选择变成对新范围的同意。明确放弃旧草稿不抹去已提交回执与未确认动作恢复入口。

## R03：业务状态各自处理

“统一样式”只统一视觉，不统一缓存、自动重试或成功判定。

| 对象 | 读取、失效与恢复 | 在折叠摘要中保留 |
| --- | --- | --- |
| Memory 正文／草稿／候选／镜像预览 | 首次连接先核验，断线和修订变化隐藏；失败保持未核验；旧实例／旧修订响应无效；确认删除清除相应可复用正文 | 连接／核验状态及重新核验入口，不保留旧正文摘要 |
| Memory 未确认命令 | 缺有效回执保持待确认；自动恢复只查询，显式同 ID 重送沿原规则；普通 404 查询不证明未提交 | 原操作身份、待确认与可执行核对入口 |
| 遗忘 | 不可变删除回执与当前进度分列；needs_scope 可与清理失败并存，全部范围及副本核验完成才 complete；新证据可重新打开进度 | 数据库删除事实、范围待确认／清理中／失败、具体未完原因 |
| 提炼／镜像 | 沿原页读取与失效，不因收起解除核验。候选和文件确认失效后不展示旧正文；重试区分恢复提交与可能重新调用模型 | 批次／镜像状态、待审批／冲突／失败及有条件的下一步 |
| 当前流程拓扑 | 展开／手动读取，无轮询；失败保留已有成功快照并明确标旧；明确无图撤掉旧图；收起、离页、断连或已知进程变化取消在途读取资格，重连只更新提示不自动读取；同结构保留视口和选点，结构改变清理旧选择 | 当前／旧快照身份与读取失败，不能暗示实时执行 |
| 路由统计 | 展开、重开、改范围或显式刷新单次读取；刷新、收起、断连或进程改变清旧结果；拒绝迟到响应 | 未读取／需刷新／读取失败；失效后不保留旧比例做摘要 |
| Tools | 打开、focus、重连和核对读取；失败／离线保留草稿并标当前状态待核验；变更掉回执只回读，不自动重送 | 配置、保存、生效与草稿差异；无法核实授权不能显示外部能力已获准可执行，本地工具不因外部授权故障被禁用 |
| 聚合 | 一次显式提交，已知 Run 的观察不等于重跑；准入未确认不自动重发，保存失败不通过重新生成恢复 | 提交／起草／保存／未保存／未知准入、原 Run 入口 |

读取失败、明确为空、无匹配、明确不存在、未执行、运行失败、未保存和未知结果分别使用文字表达。部分失败不会因另一部分成功而消失；尤其镜像失败不否认数据库已保存，图缺证不推断 Run 失败，已连接不证明工具获准执行。

## R04：Memory 内容区

依据：Q1、Q4、Q9；[Memory 实现合同](../../implementation/issue-46-memory-page.md)。

- 语义与情景分别保留搜索、主题／时间筛选、显示全部、稳定分页与游标失效后的重读。现有 `?tab=semantic|episodic|skills` 及标签方向键仍可用；不新造仅为详情显示而必须分享的路由。
- 语义表单为主题与事实；情景为摘要、发生起点与可选终点。时间输入、带 offset 的传递、半开查询边界及瞬时语义沿原协议；不因日期控件美化更改范围。
- 列表与详情均能辨识创建来源、最近修改来源、保护和版本。详情完整展示手填／工具写入／提炼来源及其合法入口，明确无来源与历史关联未知分别显示。
- 保留每类一个当前详情目标；列表后设独立页内详情区，保留回到列表入口，详情与列表查询分开，防止搜索或分页变成隐式重新选择。用户选择记录时可立即定位到详情标题并显示加载状态，读取返回不重新夺取焦点。编辑保留 `expected_version`，冲突展示当前记录与原草稿，只有显式选择才采用当前版本；重复内容不自动合并。
- `saved`、`already_exists`、已修改、内容无变化和保存待确认按真实结果显示。手动保存继续走共享命令服务，忙时 409、不排队、不另建 Run。
- 人工保护是提炼改写约束的领域状态，详情不增加“解锁”开关。用户仍可经既有明确编辑／删除路径操作。
- 删除确认位于详情，明确对象及正在显示的版本和遗忘范围说明；确认前完整内容可访问，不能仅凭三行列表摘要执行删除。版本改变使旧确认失效。成功后不回显正文／subject，以无正文回执与当前遗忘进度承接。
- 记录已不存在时清除相关编辑与可复用请求正文；单次读取失败不等于不存在。失效核验和旧请求拒收继续覆盖未展开的详情。

## R05：Memory 维护、Skill 与人格路径

依据：Q1、Q5、既有提炼／遗忘／Skill 合同。

| 区域 | 必须保留的内容与动作 |
| --- | --- |
| 操作回执／遗忘 | 本标签页操作身份、不可变提交结果、当前清理状态；查询／同 ID 恢复；遗忘范围、版本和历史组成员确认；重试清理。未确认与未完成条目不被已确认历史的 20 项边界挤掉 |
| 提炼队列 | 当前筛选及每页最多 50 会话／50 批次、上一页／下一页；有效聊天累计与阈值、超限来源跳过；批次来源区间、候选差异、整批批准／拒绝／重试、真实模型／Attempt 计量。历史 Session ID 原样传递 |
| 检索统计 | 原全部／当前会话范围和窗口、S/H/M/E 次数；三个比例分别为跳过 S/(S+H+M)、命中 H/(H+M)、错误 E/(S+H+M+E)，零分母为无可计算样本；未记录／未评估／不完整／旧证据排除。没有独立 M 比例；不借 Overview 的自然日范围或新图样式改口径 |
| Markdown 镜像 | 当前状态、合法预览、同步重试；外部改动后显式确认重建，确认绑定既有文件身份。单向派生，失败与数据库保存结果分列 |
| Skill 目录 | 启动快照中的名称、描述、内置／用户来源、整体覆盖标志、完整正文；缺目录是不可用而非空。使用仍通过 MainBar `/skills`，新增文件／create_skill 后重启加载 |
| 人格 | Tools 可发现 read_persona／update_persona，经 MainBar 普通 Run 操作；完整读取、版本、覆盖状态、修改冲突、下一 Run 生效与显式文件覆盖限制保持 |

“查看提炼批次”能展开并定位到指定批次，包括不在当前队列页的旧批次；不得伪称它属于当前分页结果。更换队列页／筛选或来源失效时，迟到候选不能回到新范围。记录选择、候选批准、遗忘范围与文件重建分别使用原业务身份，不用一份“已确认”界面状态替代。

## R06：Behaviour 设置与手动聚合

依据：Q2、Q5、Q9；[手动聚合规格](../issue-27-manual-aggregation-spec.md)。

1. 上方消息分流区同时展示已保存值、待提交选择、保存结果与恢复入口；启用／关闭默认及下一 Run 生效规则保持。显式保存、核对当前值、备份损坏文件并恢复为关闭是不同动作。
2. 配置版本冲突、磁盘外改、格式不支持、损坏和不可读分别显示。用户草稿在只读核对后仍可比较，不由刷新或展开图覆盖；不可用配置的恢复仍以原指纹为准。
3. 下方手动聚合区保留目标 Session、目标、关键词、语义／情景／会话窗口三来源、会话列表刷新与生成。显式全不选来源仍合法，走原 NoAction，而不是新增表单阻挡。
4. 提交冻结当时请求，切 MainBar Session 或后续改字段不迁移在途请求。聚合目标 Session 是本表单的选择；查看结果、Run 或来源不隐式选择 MainBar Session。
5. 未选择、读取失败、尚未读取、已读取的来源分开；提供、容量排除、许可排除、窗口排除与未取完按真实结果显示。无资料／无动作原因保持独立，未知不用零填。
6. 合法草稿属于指定 Session；Behaviour 展示同一 Run 的事实与入口，未验证候选不得作为交付结果。保持聚合草稿不自动进入后续窗口／提炼、不额外调用工具／补搜／普通 Agent 回退的边界。
7. 原资料查看重读当前对象并核对版本和使用许可；失效／遗忘隐藏已显示原资料，历史草稿可人工查看不代表被删来源仍可取回。
8. 准入未确认、忙态、起草／保存／未保存和失败恢复分别显示。确认 Run 接受之前不猜测新 Run 身份；只读恢复不重投生成。
9. 准备过的资料不等于实际发送。发送前或重试前来源失效／无法核验，按原合同终止，不能当普通来源失败降级继续；prepared／not_sent 不计实际提供。NoAction 没有助手正文，生成后记录失败与重启后不能证明终态的 interrupted 亦分别表达。

## R07：Behaviour 流程与统计

依据：Q6、Q7；[拓扑实现](../../implementation/issue-75-topology.md)、[统计合同](../../routing-statistics.md)。

- 两张图分别沿当前发布的 message_routing 与 manual_aggregation 读取，默认收起，拥有独立读取身份、视口与选择；无日历示例节点、拖拽编辑或连线修改操作。
- 图上保留只读当前拓扑身份、节点类型、条件标签、普通／条件／错误边图例、出口含义。相同端点的 full／fallback 仍是两条具有各自标签的边，图和文字清单来自同一拓扑；不兼容协议整体拒绝，不拼半份新图。鼠标平移与点选分开；放大、缩小、四向移动及适应全图均有键盘可达控件。
- 展开顺序为全宽图、选中节点说明、完整节点／边文字清单；原始定义和技术字段折叠。文字清单覆盖所有节点与边，不用悬停提示替代；未知但合法的节点／分支仍以原身份和“暂无说明”可达。
- 历史 Run 的当时拓扑与执行路径沿 Run 证据入口，当前图不能用于补齐裁剪、缺失或旧版本路径。图中静态强调不冒充某次执行高亮。

## R08：Tools 目录与授权

依据：Q3、Q8、Q9；[Tools/Ops 规格](../issue-32-tools-ops-spec.md)、[ADR-0005](../../adr/0005-availability-and-authorization-are-orthogonal.md)。

1. 一级分组依次为内置工具、各集成来源、各 MCP 服务器；集成来源与服务器采用稳定名称次序，组内按工具名称稳定排序，同名用完整身份区分。状态变化不改变排序，不把工具描述或名称片段当来源分类器。
2. 来源使用真实 `source_id` 与 MCP `server_key` 等字段；未知来源如实标记并保留身份，不归入“内置”。MCP 来源身份不同但显示服务器名相同时不能合并授权或历史。
3. 行摘要包括名称、简述、副作用、适用可用性／连接观测、保存授权和生效／未知状态、模型暴露及阻止原因。允许换行；与选择无关的长技术身份可进入明细，但关键异常和同名区分不可隐藏。
4. 明细展示完整来源／能力身份、完整描述、MCP 原名／别名、观测来源与时间、适用授权编辑及历史入口。可同时展开多项；每项仍是 unset／allowed／denied 草稿加显式保存，本地工具显示不需要外部授权。
5. 顶部持续显示授权配置可读性、保存 revision、应用状态、外部修改和在途旧政策提示；提供核对当前授权、重新应用已保存授权。逐项明细中的保存值不冒充生效，MCP 已连接和可用数不冒充已授权。
6. 草稿绑定完整能力 identity 与基线 revision，核对／focus／重连后保留比较与冲突；显式“基于当前版本继续编辑”才换基线。保存回执之后仍按原协议回读，匹配回执与当前事实才确认相应结果；结果恰好等于草稿不能证明原命令成功。
7. 能力消失、换来源或同名新身份出现，不把旧草稿或授权转移过去。历史不可调用目录保留原身份与原因，不能因重新出现同名而恢复已退休授权。
8. 请求数、调用结果、后续核验和费用仍归 Ops／Run。每项保留 `/ops?tool=<identity>`，查看包含该工具的完整 Run；同 Run 其他工具仍在，模型费用不归因给单一工具。继续到 Run 沿原快照和规范化筛选返回，过期时显式刷新。
9. 凭据、连接探测、MCP 应用／重连／清理仍在 Connections；主对话仍是正式工具请求入口。目录没有逐工具次数、成功率或 schema 编辑数据，不据原稿添加新摘要或直接运行按钮。

## R09：用户路径与验收交接

完整路径、独立反例、可复用套件和所需观察见 [ACCEPTANCE.md](ACCEPTANCE.md)。它们是将上述设计落实到真实页面的待执行要求，不能将现有测试名称、静态源码检查或原型截图标成迁移已经通过。

实施需承接 #87 的页面所有权与离页守卫；本票只具体化三页。现有原生包内 JavaScript／CSS 与同源策略保持。后端命令／schema 不因本设计自动扩展；若确需补足展示接口，先核对既有数据是否足够并显式记录合同变化。

主要需要改动的前端行为包括单列详情与摘要、维护区折叠及摘要、图文布局和统计条形图、来源分组工具行，以及不会丢输入的页内切换／刷新。当前已实现路径和新增迁移行为的区别在 FACTS 中保留，不倒写旧实现或验收状态。

## 整合假设与未决项

- 默认详情收起是初次进入的视觉状态，不是停止已有数据核验或放弃恢复责任。
- 输入保留指已有页面内所有权；Memory 同操作恢复、MainBar 按 Session 草稿和 Tools／聚合临时输入各沿原范围，不新增统一持久草稿机制。
- 三页均可用已有真实事实表达当前目标。人格编辑器、逐工具次数、全量待办统计、可编辑图均不属于两轮确认。
- 以上是 Q1–Q9 与既有合同的落实，不增加新的产品取舍。三页事实核验中发现的文字歧义已修正并保留记录；没有需要拆出的独立业务决定。整合复用两轮明确确认，后续实现如发现真实冲突须重新记录。
