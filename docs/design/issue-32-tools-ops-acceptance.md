# Tools 与 Ops：验收清单

状态：已定稿。对应 Q1–Q28 的本验收清单已获用户整体确认。本清单是未来施工要求，本次未执行下述功能测试。

设计：[整体设计](issue-32-tools-ops-spec.md)。决定：[Q1–Q28](issue-32-tools-ops-decisions.md)。

本清单已完整纳入 [Tools 与 Ops 施工规范](https://github.com/nineofoursyrup/Agent-Alfred/issues/55)。

每条以公共调用路径和可观察事实验证；夹具须接真实业务接口，不能只测试手工拼出的 UI 状态。external 夹具不代表真实外部服务验收。

| ID | 场景与必须观察到的结果 | 决策 |
| --- | --- | --- |
| A01 | 临时 Host、SQLite 与 ScriptedModel 经 MainBar 调用真实内置写工具；Tools 定位能力，Ops 定位同一 Run/请求，业务结果、Attempt 与计量相符，无直接执行表单 | Q1–Q3、Q12 |
| A02 | 真实目录仅含实际注册工具；被模型隐藏的注册工具仍可管理，本地工具不显示 external 授权开关；正式目录无测试外部能力 | Q1、Q7 |
| A03 | 注入 external 的 configured×unset/allowed/denied 六格，真实 Schema、空参数引导、隐藏及执行检查逐格一致；未验证不显示已连接 | Q7、既有矩阵 |
| A04 | 授权保存经过 mutation gate；运行、记录待落定时立即 409，无排队或中途策略切换；成功后 Schema 和执行检查均见新版本 | Q7、Q25 |
| A05 | 两标签旧版本或磁盘外部变更保存失败；原字节与生效状态不被覆盖，草稿保留并能比较当前值 | Q20 |
| A06 | 保存响应丢失、损坏或迟到时先回读且不自动重送；值相同不伪造原提交回执，旧响应不能覆盖较新状态 | Q20 |
| A07 | 缺授权文件得到合法初始状态；坏文件/新 schema 保留字节，external 暂停而本地聊天可用，错误不冒充 unset/denied/连接失败 | Q19 |
| A08 | 写入成功后注入应用失败，显示已保存尚未生效且不沿用旧 allowed；显式重新应用或正常重启完成一致应用后才恢复 external | Q25 |
| A09 | 同名不同来源能力不继承授权；历史仍指向原身份，当前未注册时无授权操作；同一已确认身份不因改显示名变成另一能力 | Q17、Q21 |
| A10 | local_read、local_write、external 夹具均有工具请求计量；无 EventSink 也记录；拒绝、引导、非法参数、未知工具和批次停止剩余请求均明确未启动 | Q9 |
| A11 | committed 请求按 Run/Step/call_id 唯一配对；aborted 工具块不计成已接受请求；同身份回执回读不重复计动作/成本，新身份同参数仍可构成新动作 | Q9、Q12 |
| A12 | 工具计量登记持久化失败时工具体未进入；执行后计量收尾失败停止后续工具和模型，动作事实不被改写成失败或自动撤销 | Q13 |
| A13 | 请求登记后、执行前、执行中和返回后收尾前分别中断；恢复保留能证明的事实，启动未确认单列，不以持久意图冒充启动，不把控制异常变普通成功 | Q14 |
| A14 | 本地 SQL 写与业务账/计量收尾遵循调用方事务；回滚不留下成功证据；文件/external 按真实恢复协议显示不确定，既有回执保留 | Q4、Q13–Q15 |
| A15 | 计量故障后新 Run 被拒，历史只读仍可用；修复和持久化/恢复验证后可发新请求，旧动作不自动重放；单笔业务 unknown 不永久锁死健康存储 | Q26 |
| A16 | 后一 Run 核验原文件操作成功，原调用观测保留并出现独立当前核验；链接正确且原成本不重计，恢复 Run 的新 Attempt 正常计量 | Q15 |
| A17 | 模型 exact、estimated、unknown 混合时分别汇总；不显示不完整总费用，aborted/retry 仍计；逐维来源、缓存口径、缺失与零保持区别 | Q5、Q12 |
| A18 | 工具不计费、已报告计量、未知、旧未记录分别显示；不同服务同名 credits 不相加，不与 USD 模型账合并；非法计量数据不能参与求和 | Q4、Q5 |
| A19 | trace 裁剪/损坏后仍读持久模型与工具计量；正文按可用性降级，Run 业务结局、trace_incomplete 与裁剪事实各自保持 | Q4、Q6 |
| A20 | 进行中、保存中、记录失败、终态缺 telemetry 各有明确提示；空 attempts 不自动当零，已独立持久工具事实可见并注明缺口 | Q10、Q16 |
| A21 | 单条旧记录损坏不抹掉其他有效行，未知 Attempt 数不猜；数据库整体读取失败不变空账；无 Run 旧消息不制造 Run | Q16 |
| A22 | 模型身份缺失但有有效端点报告金额仍保留精确事实；其余不能用当前指派猜历史价格；完整零调用与未知覆盖可区分 | Q5、Q16 |
| A23 | 列表、汇总、翻页、展开和跳转 Run 的金额使用同一记录/价格快照；期间新增 Run、修改覆盖价或目录换代不混入旧结果 | Q11、Q12 |
| A24 | 刷新后统一重读重算并标计算时刻；旧快照期满/被回收/重启后停止加载新财务明细，保留筛选及旧状态，刷新失败不混批 | Q11、Q18 |
| A25 | 资源上限下拒绝或明确失效，不将截断成员集当全部历史；快照无参数和结果正文，查询后无长期占用的 DB 事务 | Q11、Q18 |
| A26 | 7 自然日、今天、30 日、自定义半开区间在夏令时前后正确；非法时区拒绝不静默 UTC；开始时间/未开始受理时间归属按快照固定 | Q8、Q22 |
| A27 | 全局包含 chat/probe/consolidation 等实际 Run，筛选会话不切 MainBar；工具筛选保留匹配 Run 全部账目并高亮相关请求，不冒称模型费用归因 | Q3、Q24 |
| A28 | 模型投影保持当次脱敏和截断事实，审计按需读取；当前阈值变化不重算旧投影，缺失时不反推正文；删除、待核验、预算或计量停止使投影未进入下一模型请求时，不能仅凭投影存在显示已发送/已收到 | Q6、Q13 |
| A29 | 提交参数仅来自唯一配对的 committed 历史块，敏感字段及已知密钥被遮罩；aborted、跨 Run、重复身份和缺失参数不误配 | Q28 |
| A30 | 超长内联和工件审计可纯文本逐段读完；UTF-8 边界不丢重字符，当前段范围准确，浏览器不累计全文，不执行 HTML | Q27 |
| A31 | 任意路径、伪造工件引用、符号链接、跨 Run 目录、文件替换及内部损坏均被拒绝；读取与裁剪竞争有确定结果，不读取被替换文件 | Q6、Q27 |
| A32 | 页面切换、断开、异常、关闭 HTTP 时，正文请求和文件句柄正确释放；在途读取排空后才释放宿主资源，迟到读取不恢复离页正文 | Q23、Q27 |
| A33 | 历史审计断线保留当前段并标离线、不可续读；重连重验发现裁剪/不可读则清正文；HTTP 与浏览器不持久缓存正文 | Q23 |
| A34 | 删除记忆后当前受管视图与自动复用遵守遗忘限制，新的删除回执无正文；删除前原 trace 仍可人工查看，不产生新的可复用正文库 | 既有 ADR-0007、Q6 |
| A35 | 错误说明区分明确未执行、确定失败、启动/结果未知和待核验；execution_error 不统一导向改参数重试，无隐式重试/取消/直接执行入口 | Q2、Q13–Q15 |
| A36 | 原有会话、工作记忆、遗忘/提炼、模型费用、工具幂等、浏览器重连与 HTTP 关闭回归通过；依赖可注入、无 key 的默认全离线门禁通过 | 既有仓库门禁 |

施工验收执行项目规定的 Ruff、离线确定性测试、浏览器测试、类型检查、skills/环境示例校验及打包安装门禁，并记录实际结果。数值精度、迁移历史形状和故障恢复须有针对性回归。不能以测试条数或仅静态页面截图代替上述行为验证。
