## Resolution：Dashboard 三栏壳层与主对话交互已确认

用户在 live exchange 第一轮回复「全按建议」确认 Q1–Q3，第二轮回复「都按建议」确认 Q4–Q7。本票产出 `DASHBOARD-SHELL-SPEC-r1`，承接父地图 #85 与已完成的 #86 视觉基线。

### 决定

1. 十页导航按「工作区：总览、收件箱、运行、记忆」「Agent 配置：模型、连接、行为、工具」「诊断：用量账本、数据库」分组。`/overview` 为总览，`/` 进入总览，旧九页及 Run 深链接保留。
2. ≥1100 CSS px 采用左 232px、中央弹性、右主对话 320px，右栏默认展开且可收起；<1100 使用中央页、导航抽屉与全宽主对话，导航和主对话互斥。首版固定栏宽。
3. MainBar 仍为本标签页所选 Session 的唯一正式主对话，一份壳层状态与 Stream 持续持有会话、草稿和事件连接。开页、导航、收起、展开与调整视口不创建／切换 Session，不自动发送或重跑。
4. 面板显隐不算离页。真正导航可能丢失未保存页面输入时，提供「留在此页」／「放弃并离开」；保存仍在原页显式进行。确认离开后继续执行 Database 清理、Memory 核验与遗忘等原有生命周期，不统一缓存所有页面。
5. 窄屏浏览器返回先关闭面板，再返回业务页；导航／主对话互换只占一层，前进可恢复有效面板。宽屏开合按标签页跨导航、刷新记忆；窄屏刷新回中央；跨断点优先保持正在编辑的区域。
6. 主对话隐藏时仍有可见运行／正在保存／未保存／断连状态及详情入口；新回复提示直到用户看到最新回复，不自动展开、不抢焦点。Run 结局、记录状态、正文加载与过程缺口分别表达。
7. 中央和消息独立滚动，读历史时不强制拉到底；长代码与表格局部滚动。切页聚焦页头；窄屏主对话先聚焦面板标题，关闭恢复触发控件；异步响应不得抢回已移开的焦点。沿用 Enter 发送、Shift+Enter 换行、IME 确认不发送。

规格给出路由、所有权、历史与恢复状态表，15 条完整用户路径和 24 个有独立失效方式的关键反例。后续实现需覆盖十页导航、单一 EventSource、同一正式回复去重、标签页隔离、发送不确定／409、未保存／断线、原生前进后退、深链接、刷新、键盘、窄屏和页面内容保护；复用现有浏览器与离线服务接口验证，不把示例视觉或模拟环境冒充真实业务证据。
