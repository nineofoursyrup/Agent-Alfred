## 沿用的已确认约束

1. 深色中文界面，品牌 Agent-Alfred；十页共享 #86 的颜色、层级、组件与状态表达。
2. MainBar 是跨页面共享、本标签页所选 Session 的唯一正式主对话，不计作第十一页；Chat 指同一区域。Run 详情继续提供过程证据。
3. Overview 是真实指标、静态架构说明与最近 Run 的入口；本票不决定指标名单或架构内容。
4. 开页、收起、重新展开与普通导航不创建或切换 Session。新建会话和继续已有会话仍是显式操作；打开会话只读预览不等于继续会话。
5. 一个壳层持有一份主对话状态与 Stream；页面导航和面板显隐不重建 EventSource。显式会话切换与断线恢复仍可替换连接，同时保证旧连接已释放。
6. Session 与对话输入草稿保持标签页隔离。两个标签页显式选择同一 Session 时可以看到同一会话，但编辑草稿与界面状态不互相覆盖。
7. Run 结局、记录状态、正文加载状态、连接状态和过程缺口分开表达；成功与未保存可以同时成立。
8. 202、409、断线、运行中和记录失败的既有准入规则继续适用；页面导航或重新展开不自动发送、重新执行或排队。
9. 原生包内资源、无 CDN、同源 CSP 继续适用。视觉原型的样例数据和运行时不是产品输入。

### Q3：草稿与页面未保存输入

- 对话输入草稿按现有 Session／标签页规则保留。
- 打开或收起主对话、导航抽屉不算离页，中央页面未保存输入保持原样。
- 真正切换页面且会丢失未保存输入时，提供「留在此页」与「放弃并离开」。保存仍须在原页面显式完成。
- 用户确认离开后执行各页原有清理规则，包括 Database 清空 SQL 与结果，以及 Memory 的核验与遗忘保护。
- 该决定没有把所有业务页面变成长期缓存。取舍见 [ADR-0046](../../adr/0046-panel-visibility-preserves-page-lifecycle.md)。

## 第二轮：用户已确认

### Q4：返回与面板历史

窄屏打开面板时，浏览器返回先关闭面板，再次返回才返回上一业务页。导航抽屉与主对话互换只占一层；从面板进入其他页面后关闭面板，后退回此前业务页。前进可恢复仍有效的面板状态，整个过程不切换 Session。

### Q5：布局偏好的记忆范围

宽屏主对话的展开／收起按标签页记忆，跨页面和刷新保留。窄屏刷新或直接打开深链接默认显示中央页面；两种布局的偏好分开，跨断点时优先保住正在编辑的区域。标签页之间不主动同步布局偏好；会话和对话输入草稿继续沿用已有规则。

### Q6：主对话隐藏时的状态

壳层保留可见状态入口，显示运行中、正在保存、未保存、连接中断，并提供查看主对话和当前 Run 的详情入口。新回复到达时显示「有新回复」，直到用户看到最新回复；不自动展开，不抢焦点。Run 结局与保存状态继续分别显示，关键异常持续可见。

### Q7：滚动、焦点与长内容

中央页面与消息列表独立滚动，长代码与表格在自身区域横向滚动。消息列表原本在底部才自动跟随；用户翻旧消息时保住位置，提供「回到最新」。切换业务页后聚焦页面标题；窄屏打开主对话先聚焦面板标题，输入框由用户主动进入；关闭后回到触发控件。发送或后台加载结束时，用户已转到其他区域就不把焦点拉回输入框。

发送键沿用现有 Enter 发送、Shift+Enter 换行、中文输入法确认不发送。该语义已随第二轮说明再次保留，没有新增快捷键或自动发送方式。

## 浏览器平台事实

- `sessionStorage` 按 origin 与标签页隔离并跨刷新保留；带 `opener` 的页面可能以创建者存储的副本起步，之后互不影响。因此「标签页隔离」不能被简化为「两个标签页绝不可能最初选中同一 Session」。[MDN sessionStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/sessionStorage)
- History API 可以在同一 URL 下添加历史状态；部分浏览器会持久保存该状态，不能将草稿正文或受保护查询结果塞入导航历史。[MDN pushState](https://developer.mozilla.org/en-US/docs/Web/API/History/pushState)
- 刷新／关闭文档的离开提示由浏览器控制，依赖用户交互，且移动端可能不触发；文案也由浏览器决定。Q3 的应用内两选提示不能冒充对强制退出或系统回收的持久恢复承诺。[MDN beforeunload](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event)

上述是设计时核对的平台边界，不是本次真实浏览器或移动设备验收记录。
