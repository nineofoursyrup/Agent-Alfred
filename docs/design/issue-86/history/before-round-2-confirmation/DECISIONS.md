## 第一轮确认

用户对以下建议回复“全按建议”。

- Q1：保留参考稿深黑底、紫色强调、细边框和卡片层次；允许提亮承载信息的辅助文字。普通信息文字至少 4.5:1 对比度；逐项记录与原稿的差异。
- Q2：采用中等紧凑密度。正文与聊天 14px、表格 13px、辅助信息最低 12px；数字与标识采用等宽字体。原型仍需用户目视确认。
- Q3：参考视口 1440×900、1280×800、390×844 CSS px；另检查 320px 宽度与文字放大后的可用性。具体栏宽、面板切换与焦点规则交 #87。

对比度依据：[WCAG Contrast (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。上述规则是本票已确认的检查条件，不代表整个产品已经通过 WCAG 认证或全部标准检查。

## 原型 r1：等待用户审阅

入口：[dashboard-prototype.html](dashboard-prototype.html)。单文件、原生 HTML/CSS/JavaScript，可直接打开；无需账户、数据库、联网字体或参考稿运行时。所有样例状态只存内存，刷新即重置。

为遵守“本票不实施产品”，原型位于设计文档旁，不改生产路由或 `ops/static`。保留已确认三栏视觉；三个版本在中央工作区采用不同信息顺序，以回答“同一视觉语言下，哪种层级更合适”：

| 方案 | 总览 | 密集运行页 |
| --- | --- | --- |
| A 架构优先 | 指标卡 → 静态架构 → 最近运行 | 表格 → 详情 |
| B 最近运行优先 | 连续指标条 → 最近运行 → 静态架构 | 详情 → 表格 |
| C 左右分区 | 左侧指标/架构，右侧运行列表 | 左侧列表，右侧详情；空间不足时堆叠 |

URL 参数：`?variant=A|B|C&page=overview|runs|components&state=normal|edge`。底部评审工具切换方案、页面和状态；左右键可切换方案，在输入框、选择框或可横向滚动表格中不拦截。评审工具和样例标记属于原型，不属于产品设计。

公共组件页包含颜色、字级、表单、错误、空、加载、过期、断连、禁用原因和焦点样例。边界状态包括“回复完成 · 未保存”“费用未知”和“证据部分缺失”；颜色始终附带文字和标记。原型没有自动脉冲、打字或架构执行动画。

## 尚未解决的设计树
