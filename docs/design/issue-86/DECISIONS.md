## 公共组件表达

- **卡片**：低亮度面板、1px 装饰边框、12px 圆角；标题、说明、内容分层。避免让每个内部字段都变成独立卡片。图示必须携带“静态说明”等明确身份。
- **表格**：13px 正文、12px 表头/元数据，数值和 ID 等宽；细行分隔、清晰选中行。表格在窄屏可局部横向滚动；不通过压小字号、隐藏结局或记录状态维持密度。
- **表单**：常驻标签、字段邻近的说明/错误、可辨认输入边界。禁用原因在旁显示；焦点不能只依赖颜色微变。占位符不代替标签。
- **详情**：标题、关键状态、字段、过程分组依次呈现。Run 的阶段、结局、记录状态、过程证据和费用分别表达；正式回复由 MainBar 承载。
- **正文与长内容**：正文、错误说明和消息可换行；关键状态不以省略号截去。代码、表格和图示保留有名称、可键盘访问的局部滚动区域。
- **字级与间距**：通用字级 14/13/12px；标题、指标数字按 tokens 使用更高层级。采用原型已展示的紧凑间距，包含基础 4/8/12/16/24px 及组件专用 10/14/18/20/22/28px；不将间距示例误当作一个必须重新排版的封闭刻度。

## 状态和反馈

| 事实 | 公共视觉规则 |
| --- | --- |
| 已完成 | 绿色文字/标记；只证明该结局，不替代保存、支持或证据状态 |
| 未保存、过期、部分缺失、需要注意 | 橙色标记或提示，保留具体原因；与成功结局可并列 |
| 失败、输入无效 | 红色文字/标记或邻近提示；保留重试/修复说明，不折叠成空状态 |
| 未知、未观测、不可用 | 明确的中性文字；需要用户处理时可另附橙色提示，不换成零或成功 |
| 正在运行、当前选中 | 紫色强调及明确文字；不由自动闪烁证明运行事实 |
| 加载 | 明确“加载中”文案；静态占位可辅助，不能伪装已加载数值 |
| 明确为空 | 对应空文案；与加载失败、证据缺失分开 |
| 断连 | 持续可见的连接说明，内容、草稿及业务恢复规则交 #87 |

颜色均配合文字或标记。问题未解决时重要提示持续可见，不自动计时消失。动效不携带独占信息；允许的短过渡只影响颜色/透明度，最长 150ms，`prefers-reduced-motion: reduce` 时禁用。获批原型的零过渡符合该上限。

## 检查条件与参考视口

所有尺寸均为 CSS px。主视觉基线 1440×900；1280×800 检查拥挤；390×844 检查窄屏；320×800 为最窄检查样例。布局切换只展示可能形式，#87 冻结正式栏宽和面板规则后，须用相同视口再次核对其与本视觉基线的兼容性。

- 普通信息文字实际前景/背景对比度至少 4.5:1；不对门槛四舍五入放宽。控件识别与焦点按获批样例检查；已抽查控件边框 3.190:1、焦点轮廓 9.041:1。纯装饰分隔线不承担控件识别或状态信息。
- 键盘可到达所有可用操作和需要滚动的内容区域；焦点轮廓清晰且不被遮挡。原型焦点为 3px；正式面板焦点归属与返回路径由 #87 规定。
- 标准视口无整页横向溢出；表格、代码与图示可局部滚动。扩大文字后内容与操作仍可访问，重要状态不裁切。现有 200% 字号覆盖检查不冒充原生浏览器缩放或真实移动软键盘验收。
- 减少动效时无循环动画或过渡，状态信息完整保留。

## 参考资产身份与验收方法

1. `reference/` 的原稿 HTML 与原始 WebP 保留逐字节身份；原稿原有语义、演示数据与运行时不因保存而成为产品契约。
2. `baseline/r1/` 保存获批 A 原型、tokens、代表性截图及独立 manifest。原型选择固定为 `variant=A`。该目录冻结后不覆盖；有后续修订则新建版本，并记录受影响的决定与批准来源。
3. `APPROVAL.md` 将两轮用户答复绑定到所审阅的原型 SHA-256、选择和范围；`manifest.json` 区分当前文档、批准基线、历史参考与 B/C 对照。
4. 先核对版本、视口、状态样例、浏览器、DPR、字体环境，再比较。共同 tokens 与结构必须相符；除本文明确允许的必要调整外，不将新布局或状态改写归为“视觉误差”。
5. 同环境截图用于定位差异；跨平台字体回退和抗锯齿差异不按逐像素失配判失败。文字因此溢出、控件因此遮挡、关键状态因此不可见，仍是失败。
6. 出现遮挡操作、裁掉关键状态、错误/未知被显示成成功、空值冒充零、缺失证据被美化为通过，均不能通过。截图相似度或产品测试数量不能覆盖这些失败。
7. 资产以专用分支 `codex/issue-86-visual-baseline` 保存；本票 resolution 的长期链接须指向实际发布后的固定 Git revision。回环地址和本机路径仅用于本地评审；基线与当前文档的摘要见清单。发布前记录留在 `history/before-publication/`。
