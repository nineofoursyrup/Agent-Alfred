# A29 确定性验收矩阵

这是待实现测试设计，不是已运行结果。规范唯一来源：[01-SPEC-SUPPLEMENT.md](01-SPEC-SUPPLEMENT.md)。编号在本补充内稳定，不覆盖 #31 原 A29；只有全部相应核心用例通过才可确认 #45 的 A29。

## 夹具与观察边界

- 临时真实 SQLite/FTS，经编号迁移和共享命令服务保存/删除。通过拟新增的公共来源/使用登记接口建图；不能直接写测试专用表替代公共行为。
- 固定时钟；同一数据库关闭后重开验证恢复。磁盘只在临时夹具中使用；本准备轮没有运行这些测试。
- 语义记录 M1，情景记录 E1；S1 的 R1、R2，S2 的 R3、R4；实际读取边 R1→R2→R3。R4 有完整且不相关的证据。另建相同正文的独立 Memory M2。
- B1 为跨 Session 来源批次，B2 为可证明无关批次。U1/U2 为无法证明安全的历史范围。以独特 subject/body/query/异常标记检查无正文出口。
- 自动读取端口以 working_window/gate_history/tool_summary/consolidation_source 四种用途参数化；#45 测核心公共读闸，真实消费者验收分别归 #16/#19/#18/#46。
- 对争用使用显式 reached/release Event，分别安排两种确定顺序。等待超时仅作测试失败上限，不拿 sleep 或重复碰运气决定业务顺序。
- 每项检查 get/FTS、确认回执、当前进度、范围成员、读闸输出及安全投影；不以私有函数调用次数作为成功证据。
