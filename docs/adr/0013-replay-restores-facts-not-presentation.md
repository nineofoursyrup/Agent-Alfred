# 重连只恢复已完成的可重放状态，不恢复暂态呈现

Dashboard 的 SSE 断线重连需要一个有界重放缓冲。缓冲里装什么，决定了它在最需要它的时候
是否还有内容。

装全部事件看起来最"完整"，但算一下就知道它是个陷阱：`block.delta` 与 `tool.progress`
是逐 token 的，一次长回答就是几千帧，2048 帧的窗口只够十几秒。而断线恰恰发生在
网络抖动、笔记本合盖、标签页被浏览器节流之后——**那正是窗口必然已经滚出的时刻**，
于是每次重连都是 `replay_gap` + 全量重载，缓冲形同虚设。反过来，只装可重放事实时，
同样的 2048 帧能覆盖几百个 Run。

因此**只有 `replayable` 事件进入重放环**。v1 里这个谓词派生自
`trace_policy == "persist"`，但它**必须另有其名**：`trace_policy` 回答的是
"该不该写进 trace"，`replayable` 回答的是"重连时该不该补发"，两者今天同真是巧合。
把它写成"persist 事件进环"，等于把两个独立的轴焊死在十几个调用点里——
而这正是[ADR-0004](0004-flush-barrier-at-run-end.md) 一带的
`trace_policy` / `flush_at_run_end` 已经掰开过一次的错误。

由此接受一个代价并把它写在明处：**重连后，未收尾 attempt 的打字动画不会被补上**。
这不是缺陷，是这条 ADR 的标题本身——重放恢复的是**事实**，不是**呈现**。
那次流式回答的内容由 `attempt.committed` / `attempt.aborted` 的块快照承载，
与 trace 读取端重建历史用的是同一条规则（trace 里同样没有增量）。

## Consequences

客户端契约多出一条：**重连时必须丢弃任何进行中 attempt 的已渲染增量，等收尾快照**。
不这样做，屏幕上会留下一段永远等不到结尾的半截文字。

线格式随之被约束：**`id:` 只出现在"可重放且已完整"的边界上**。`transient` 帧不带 `id:`，
一个被切分的逻辑事件只有末帧带 `id:`。SSE 规范中不带 `id:` 的帧不更新
`lastEventId`，于是"浏览器游标停在不可重放位置或事件中间"在结构上不可能发生。

但规范的 dispatch 算法有一处必须配套处理：它**先**把 last event ID buffer 赋给
last event ID string，**再**在 data 为空时提前返回。新流的 buffer 初始为空，
因此重连后首个无 `id:` 的分块一经派发就会把游标清成空串。响应体必须以一个
无数据的 `id: <checkpoint>` 帧重新种入游标，且它必须排在任何数据帧之前。

游标因此是**服务端曾签发的完整事件检查点**，不是落在数值区间内的任意数——
全局序号里夹着 transient 与不可重放位置，算术前驱未必是合法游标。

## 修订（2026-08-30）：游标词汇的正式定义——`:0` 与 re-seed

本 ADR 结尾写定「游标因此是**服务端曾签发的完整事件检查点**，不是落在数值区间内的任意数」。
实现（#28）落地时出现两处该句没有覆盖、也不能由实现私自决定的边界情形，经裁决（2026-08-30，
用户批准）正式定义如下，并取代结尾一句的字面读法：

1. **`:0` 是传输启动边界，不是事件检查点。** `STARTUP_CHECKPOINT_SEQ = 0`
   （`{process_instance_id}:0`）位于事件序号之下：不消耗领域 `seq`，无任何事件在其之下，
   也永不作为 `id:` 出现在数据帧上。它存在的唯一理由是本 ADR 倒数第二段所定：SSE dispatch
   算法会把浏览器游标清空，因此流的响应体必须以某个本进程拥有的边界重种——而环从未签发过
   检查点时，这个边界就是 `:0`。它被 `classify_seq` 判为 valid 的条件不变：仅当环什么都
   没丢（`replay_floor_seq() == 0`）；一旦任何事实不可恢复，`:0` 一律 `too_old`。
2. **re-seed 重种的是「曾签发边界」，不是「当前可重放」承诺。** 环 clear（不可恢复丢弃）
   之后，重种的旧检查点不再是环能复现的事实。客户端带它回来会得到 `replay_gap`（`too_old`），
   且每次重连都会再次重种、再次报告——空洞永不静默。`latest_complete_seq`（当前可重放）
   与 `reseed_boundary_seq`（曾签发）因此是两个量，正如本 ADR 标题所定：重放恢复的是事实，
   不是呈现。

不变的性质（本 ADR 要保护的唯一性质）：**环仍拒绝一切未签发的正数 seq**——落在数值区间内
但从未签发的游标一律 `malformed`，伪造的区间内游标不能被判 valid。
