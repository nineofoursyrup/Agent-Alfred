# 聚合失败不自动进入普通 Agent 循环

#27 Q9 / D2 确认聚合专用失败结束本次起草，不进入普通 Agent 回退；来源普通故障仍按图的专属 error 边恢复，底层传输重试保留原策略。普通循环可能重新选择资料或调用工具，突破用户只从选定来源起草的范围；因此即使副作用为 `none` 也不自动进入它，这是对 #6 通用回退约定在手动聚合上的明确限定。代价是模型或图故障需用户另行生成，已发生的 Attempt 和费用仍保留。

批准来源：[手动聚合设计 Q9](../design/issue-27-manual-aggregation-design.md#q9-综合或图失败后的回退)，2026-09-14 用户回复“全按建议”。
