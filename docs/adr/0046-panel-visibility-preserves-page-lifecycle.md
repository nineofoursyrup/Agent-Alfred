# 面板显隐不触发离页，真正导航遵守页面清理边界

三栏 Dashboard 让用户在业务页面与主对话之间频繁切换，而 Database 的查询内容清理、Memory 的遗忘保护和聊天草稿各有不同约定；经 [#87 第一轮 Q3 确认](../design/issue-87/DECISIONS.md)，导航抽屉与主对话的显隐仅改变呈现，实际页面导航若会丢失未保存输入，先让用户选择「留在此页」或「放弃并离开」，保存仍由原页面显式完成。

确认离开后执行所属页面原有的清理和核验规则，不用统一的页面缓存延长查询结果或受保护内容的寿命；代价是用户须在离页前处理会被清理的输入，而主对话的 Session、对话输入草稿与事件连接继续由壳层持有。
