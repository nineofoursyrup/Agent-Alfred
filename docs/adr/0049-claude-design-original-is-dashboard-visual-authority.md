# Dashboard 视觉以 Claude Design 原稿为权威，领域事实仍分别表达

用户于 2026-10-10 在 [#122](https://github.com/nineofoursyrup/Agent-Alfred/issues/122) 确认完全照搬 Claude Design「Syrup agent repository」中 `Syrup Dashboard.dc.html` 的颜色、字号、圆角与脉冲，采用 version `1786950414092924`、SHA-256 `54807adb38541fa2966e5b0c334b9d0e8d71c60b814245601bc4f35b8ec54b84` 的[归档原稿](../design/issue-122/reference/README.md)作为视觉权威。此决定取代 ADR-0045 中「允许必要的可读性调整／提高信息文字可读性」部分、#86 DECISIONS 的 Q1（普通文字对比度至少 4.5:1）、Q2（14/13/12px 下限）、Q5（无循环脉冲）和 Q6 的 `DASHBOARD-VISUAL-BASELINE-r1` 权威身份，以及 Dashboard 实施规范第 5 节的对比度与字号下限。#86 的原稿、批准记录、tokens 和基线资产原样保留，作为历史证据。

接受的代价是眉标、元数据和表头的对比度低于 WCAG AA 普通文字要求：`#5f5e66` 在 `#0e0e10`～`#18181b` 上约 3.01～2.77:1，`#45454b` 约 2.03～1.86:1，`#6f6e69` 约 3.8～3.5:1；原稿 10～11.5px 的信息字级也不再服从旧下限。此决定同时取代 #86 DECISIONS 中「控件边框 `#686774`」的设计参数与「控件边框 3.190:1」（非文字对比度 3:1）的抽查条款；新的控件边框 `#2c2c31` 在 `#18181b`～`#0e0e10` 上约 1.28～1.39:1，输入框的可辨认改由常驻标签、占位符不代替标签、聚焦时强调色边框和 3px 焦点轮廓承担。这些取值由用户明确接受，不作为完整可访问性达标声明。原稿缺少的错误色 `#ff8f9b` 与键盘焦点色 `#b9b0ff`、3px 外轮廓继续保留；输入焦点同时采用强调色边框。`sy-pulse` 只供真实已连接或当前有 Run 的状态点使用，减少动效时取消所有动画与过渡，选中态只允许不超过 .18s 的透明度过渡。

ADR-0045 中「领域事实分别表达、演示数据不迁入产品」部分继续有效：Run 结局、记录状态、连接观测、费用三态和证据缺失各自保留文字与事实来源；原稿演示数值、专有概念和自动架构执行高亮不迁入产品。ADR-0046 的显隐／离页边界和 ADR-0047 的来源快照边界不变。#123 只切换全局视觉并提供公共配方，不绑定状态点，也不重排页面或改变壳层结构、行为、HTTP/SSE 契约和路由；后续页面票复用[公共配方](../design/issue-122/RECIPES.md)。
