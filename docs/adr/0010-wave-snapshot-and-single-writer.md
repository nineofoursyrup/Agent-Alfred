# 图的 state 契约：wave 快照、缓冲整批提交、全局单写者

几乎所有图引擎的默认做法是「节点就地改一份共享 state，后写覆盖先写」。
本项目**整条否掉**，换成三件事一起成立的契约。

**一、wave 快照。** 一个 wave（拓扑分层）内的全部节点，读到的是**本波开始时的同一份不可变快照**，
即使它们是串行跑的。这条在 v1 里不换来任何性能，只换来一件事：
将来真开并发时，**语义一个字都不用改**——并发下同层节点本来就该看见同一份输入。
反过来，如果 v1 让后跑的节点读到先跑节点的写入，那条依赖会被**悄悄写进业务逻辑**，
而它的存续条件是「拓扑序恰好是这一个」。条件边让路径不唯一，拓扑序也就不唯一，
于是这类依赖会在某次加边之后静默失效——症状是「换了个无关的分支，另一个节点的结果变了」。

**二、缓冲整批提交。** 节点返回的 `writes` 与路由决议在 wave 内保持 provisional，
波末校验「实际写集 ⊆ 声明写集」且无冲突，通过则整批提交。**未被接管的失败或整波写集校验失败使整波不生效**。
普通执行失败若被显式 error 边接管，失败节点的候选写入与转录被丢弃；其余成功节点的有效写入、失败状态与边级决议仍可整批提交，恢复节点在下一波运行。失败节点的缓冲写入永不提交。

这一区分由 [#25 设计 Q1](../design/issue-25-graph-design.md#q1-被-error-边接管的失败与波提交) 于 2026-09-13 获用户确认，消解旧文“任一失败”与已接管失败允许波成功决议的冲突。Q4 随后确认：路由失败使整波撤销并直接终止图，不再启动 error 节点。普通执行错误与非法控制流的恢复边界不同，避免引入“波已回滚、部分错误边仍生效”的另一套提交语义；Run 级强制停止规则不因此放宽。

**三、全局单写者。** 图输入声明与节点写入共同遵守：编译期建立 key 所有权表，
拒绝任何重复 writer。只管 wave 内是不够的——跨 wave 的覆盖是同一种病，
结果照样取决于走了哪条路。同语义多来源必须用不同 key，再经一个**显式的合并节点**收敛，
让「合并」这件事在拓扑上看得见，而不是藏在一次覆盖里。

单写者还是 `describe()` 那张数据流图的前提：只有它成立，「这个 key 从哪来」才有唯一答案。
票里要求 `describe()` 是拓扑的唯一来源，而一张画不出数据流向的拓扑只画了一半。

配套的读侧是 `required_reads` / `optional_reads` 两分，编译期沿可达路径做
**控制流敏感的 definite-assignment 分析**：`required` 必须在所有抵达路径上必然存在，
`optional` 至少在一条路径上有来源。运行时 `optional` 缺席就是 `Mapping` 里没这个键，
**绝不用 `None` 兼任「未执行」**——`None` 可能是上游写下的合法值，
一旦兼职，节点就永远分不清「分类器判定为无」和「分类器根本没执行」。

路由器按 [#25 设计 Q3](../design/issue-25-graph-design.md#q3-路由器读取源节点刚写下的值) 读取“波初快照 + 自己源节点的候选写入”，再按路由声明缩小视图。它看不到同波其他节点的候选；路由决议依然只在波成功决议后生效。源节点输出不在路由调用前全局提交，避免破坏同波节点的快照隔离。

Q7 确认：已发现未接管失败时立即停止尚未启动的节点和后续波，只为已 started 节点记录 aborted；未启动动作不造执行事件或账。直到波末校验才发现的错误，必须保留此前实际调用与费用的事实。

## Consequences

三条合起来意味着**节点无法把中间结果传给同波的邻居**。这是刻意的：
真需要顺序就加一条边，让那个顺序在拓扑上显形。

配置驱动的跳过因此必须**在拓扑里有位置**（`skippable_by_config=True`，进 topology hash）。
一个能改变执行结果、编译期却看不见的开关，会让「改一个设置项，某张图在运行时炸在一个
跟设置项八竿子打不着的节点上」成为可能，而 `describe()` 也就不再是拓扑的唯一来源。
但 definite-assignment 是**控制流敏感**的，不是把 skippable 节点的写入一律降为 optional：
下游若只能经该节点的 taken 边抵达，其写入仍可作为 required。一律降级会误伤被执行路径支配的合法依赖，
逼作者在所有下游写一堆永远不会缺席的 `optional`，而那些 `optional` 会训练读者忽略这个标记。

代价是作者必须提前想清楚每个 key 归谁、哪些节点可关。这正是我们想让他付的成本。
