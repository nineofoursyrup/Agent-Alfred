# 聚合草稿可在会话查看，但不自动成为来源

#27 Q5 / D2 确认新增会话关联的 `aggregation` Run，由唯一 finalizer 保存用户目标和草稿并支持正常展示及正文恢复；工作窗口、后续聚合窗口与自动提炼仍只消费既有合格 `chat`。若把草稿直接当成普通聊天，模型推断会在后续聚合和提炼中反复成为依据，因此人工可见与自动再利用资格必须分开；代价是新增 purpose 的迁移和读写适配，且后续普通聊天不会隐式读到草稿，用户需明确引用或加工。

批准来源：[手动聚合设计 Q5](../design/issue-27-manual-aggregation-design.md#q5-会话关联与自动再利用)，2026-09-14 用户回复“全按建议”。
