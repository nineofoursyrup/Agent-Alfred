# 消息分类是控制数据，不是回答转录

消息分流的分类器只接收固定指令与当前有效任务文本；其输出进入分类 state 与审计，不追加到给回答模型使用的运行转录。分类器不接收人格、Skill 正文、历史、检索正文或工具；完整回答继续独立携带已准备上下文、Skill 和发送前来源复核。此决定由 [#26 设计 Q8 / D2](../design/issue-26-message-routing-design.md#q8-分类输入与回答转录隔离) 确认。

已有通用模型节点会共享成功转录，直接复用最省接线，但会让“full”或异常分类文本变成下一模型看见的助手发言，也让分类器接收超出判断当前消息所需的资料。决定保留专用的分类输入与转录边界；代价是歧义消息更多地进入完整循环，并需单独记录分类输入和费用。不改变通用 agent_node 共享有效回答转录的规则，也不以纯快照名义取消回答的遗忘/版本核验。
