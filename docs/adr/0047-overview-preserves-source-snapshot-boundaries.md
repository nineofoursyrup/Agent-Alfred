# 总览保留各来源的快照边界

Overview 同时呈现期间账目、当前记忆库存和最近运行；用户在 [#88 的 Q5、Q7、Q8](../design/issue-88/DECISIONS.md) 确认运行记录数与模型费用共用一份账目快照，语义／情景计数共用一份记忆修订，最近运行另有读取身份与实时状态。各数据区分别标示时间和失效，不承诺整页来自同一瞬间。

一份全局快照会将价格、记忆修订、持久 Run 与进程内未保存状态绑定为新的统一一致性协议；直接在浏览器拼接第一页又无法证明计数完整。采用来源内部一致、区域之间显式区分的合同，复用各自已有事实边界，让局部不可用不抹掉其余可信结果，并接受卡片间观察时刻不同的代价。

手动刷新不会改变原有业务记录、准入或会话。来源身份、期间或记忆修订已经失效时，旧响应不能恢复当前值；导航到详情会明确重新读取，不把新的金额冒充原快照的可追溯副本。实现与验收要求集中在 [OVERVIEW-DATA-DESIGN-r1](../design/issue-88/DESIGN.md)。
