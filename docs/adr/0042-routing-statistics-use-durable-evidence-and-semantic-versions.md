# 路由统计使用持久证据与语义版本

状态：accepted；来源：#74 grill-with-docs 的 Q4、Q6、Q8、Q9，用户分两轮“全按建议”确认；完整ROUTING-STATS-DESIGN-r4随后已获用户“确认”，实施验收权威承接为ROUTING-STATS-SPEC-r1。

消息分流统计把样本资格随准入事务保存，把路由结果摘要随既有 Run 收尾事务保存；不依赖 trace 保留，不增加逐节点同步落盘。这样复用已有单写者与收尾屏障，并接受进程突然退出时部分结果未知的代价；未知必须显式显示，不能用分类结果、内存通知或缺字段推断已发生或未发生。这承接 ADR-0020/0024 的持久事实边界，不允许统计功能改变既有业务执行和记录失败语义。

各指标只在自身有证据的样本内计算比例，并显示覆盖缺口。跨 Run 可比性按稳定的统计口径版本与路由策略版本分组，不能以字段形状、topology_hash 或进程内图发布代际替代；无可证明版本的历史数据保持隔离，不补写当前版本。为统计扫描 trace、逐节点另写统计账、把所有未知合并成否都更容易产生一个看似完整却无法证明的分母，故不采用。

代价是历史数据覆盖可能较低、崩溃不能保证完整结果统计；未来口径或策略变化要显式维护版本和相应判读合同。具体验收案例留在 #74 权威设计/规范，不在此维护第二份计数规则。
