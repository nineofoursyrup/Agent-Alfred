# 冻结图与工具注册表按同一代发布

消息分流启动时编译；受控工具目录发布时允许编译新的不可变图，并与对应 Registry 在同一准入可见边界发布。每 Run 捕获同代配对，执行期间不改变拓扑，不按 Run 重编译。此为 [#26 Q16 / D3](../design/issue-26-message-routing-design.md#q16-工具目录更新时能否发布新的冻结图) 对 #6/#25“启动编译”的有限补充。

MCP 在连接/重连后会新增或删除具名工具，永久沿用启动名单会漏能力或产生无效白名单。新代际保留静态白名单、编译校验与原 topology_hash 定义，避免 wildcard 或绕过 Registry；名单变更改变哈希，schema-only 变更以能力身份和代际另记。发布失败不混用配对，也不声称已经断开的旧 MCP 连接被事务回滚；未确认的 MCP 能力沿既有暂停规则处理，安全撤销不因快照复活。代价是控制面承担候选图构建与配对发布责任。
