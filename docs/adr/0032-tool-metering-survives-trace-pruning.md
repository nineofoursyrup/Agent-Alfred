# 工具计量独立于详细追踪保留

Tools 与 Ops 需要在详细追踪到期裁剪后仍能解释已记录的工具成本。工具计量因此独立持久保存，trace 的缺失或裁剪不删除它；参数和结果正文不随计量长期保留，旧记录缺少计量事实时明确显示“未记录”，不能补成零。

继续只从 trace 读取成本可以少建一条持久记录路径，但会让保留策略删除用户核对历史消耗的依据。接受独立计量的存储与一致性成本，也避免为了保住账目而长期保存完整工具结果。它不取代用于证明副作用的工具账。

不能持久登记请求时不启动工具；执行后计量无法落定时停止本 Run 后续工具与模型执行，不以可用性为由继续扩大未记录范围。这个选择接受计量故障影响继续执行的代价；记录失败既不证明动作失败，也不授权自动撤销动作。

计量存储故障未解除时暂停新 Run，保留只读诊断；修复并通过持久化及恢复校验后才允许新的用户请求。业务结果未知本身不是计量故障，不能用修复存储为名重放旧动作。

本决定来自“调用工具并看账”访谈 Q4、Q13、Q26，用户已分项确认，并随整体验收规范完成整体确认。
