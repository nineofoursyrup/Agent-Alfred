# Syrup 视觉基线保留领域事实，并允许必要的可读性调整

Dashboard 十页迁移需要一个稳定的共用视觉来源；原始 Syrup 稿的细暗文字、演示数据和自动高亮却不能直接成为产品验收事实。经 [#86 两轮设计确认](../design/issue-86/DECISIONS.md)，采用 A 方案的架构优先层级、深色配色与中等紧凑密度，同时提高信息文字可读性，分别呈现 Run 结局、记录状态、连接观测和证据缺失。

参考还原以获批 HTML、tokens、视口截图及其摘要为共同依据。原稿身份永久保留，批准基线另行版本化；原稿与批准基线的差异显式记录。接受的代价是部分字号、文字颜色和状态表达偏离原稿，以免像素上的忠实导致信息不可读，或让漂亮的成功标记掩盖未保存与未知。原型运行时、假数据和图示业务含义不随视觉批准自动迁入产品；壳层交互与 Overview 数据合同仍由对应决策规定。
