# 在聊天中使用 Skill

Skill 是用户维护的默认执行流程。当前明确要求优先，Skill 不授予工具权限。它只提供 SKILL.md 的完整正文；附件、引用路径和脚本不会自动读取或执行。多个流程发生影响执行或交付的冲突时，助手应先澄清，暂停依赖该选择的操作。

将 [checklist 示例](examples/skills/checklist/SKILL.md) 复制到 `~/.agent_alfred/skills/checklist/SKILL.md`，重启 Alfred。若使用 `--state-dir`，请将示例放在该目录的 `skills/checklist/SKILL.md`。在 CLI 或 Web 的消息中输入：

```text
/skills checklist
请整理我这次搬家的准备步骤。
```

只有物理第一行识别 `/skills`。下一行必须有任务；名称大小写敏感，允许 `[a-zA-Z0-9_-]{1,64}`。多名称用空格或 tab 分隔，去重保留首次顺序。`/skills off` 禁用本次选择；`/skills "off"` 指定名为 off 的流程。双引号只包裹名称，不支持 shell 展开、转义或路径。第二行、代码示例中的文字不作为控制命令。

指定时只加载指定集合。名称不存在、读取失败、数量或容量超限都会准备失败；修正后重新提交。没有控制行时，选择器根据当前任务、安全的近期完整对话组和目录名称/描述选择，不读取 Skill 正文、长期记忆或历史工具账。合法空选择仍是正常回答。选择故障时只根据当前任务中直接的“使用 NAME”“用 NAME”“按 NAME”“use NAME”保守匹配，排除代码、引用及含有限否定词的分句。它不保证理解所有自然语言表达。

每次 Run 只选择一次，正文与顺序固定；后续工具往返、聊天 Graph 和合法回退复用这份快照。下一 Run 重新选择，不强制继承。原始消息仍可查看，模型历史投影会剥离已经生效的控制行。文件编辑、删除或 `create_skill` 之后需重启才改变 Catalog。用户同名文件整体覆盖内置，页面和输入说明会标注；同目录重名或非法目录配置在启动时报错。

v1 固定限制（Unicode 码点，不是 UTF-8 字节或 Token）：

| 项目 | 上限及结果 |
|---|---|
| 每 Run | 3 个不同名称 |
| 每篇正文 | 8,000 码点，完整保留 |
| 注入区段 | 16,000 码点，包含全部包装 |
| 自动选择清单 | 100 项且紧凑 JSON 不超过 16,000 码点 |

等于上限允许。清单超限整体跳过模型选择，按规则在完整目录回退；不影响明确指定。自动选择中一篇失败或装不下会跳过，并继续检查后续已选项，不另选替补、不截正文。完整模型请求还受原有规范 JSON 输入字符上限约束；固定输入放不下时明确失败，已发生动作不会重新执行。

选择器与记忆检索门复用模型指派和 `AGENT_ALFRED_GATE_MODEL_BUDGET_S`（默认每次判断 5 秒），共同受本 Run 的总期限约束。未指派检索门模型时沿用主模型；已指派但不可用时规则回退，不暗换模型。`AGENT_ALFRED_GATE_INPUT_CHARACTER_LIMIT` 同时限制两种判断；未配置则继承 `AGENT_ALFRED_INPUT_CHARACTER_LIMIT`，没有第三套设置。

顺序是 Skill 选择、记忆检索门、回答。两个模型判断都要求共享剩余 Step 至少为 2。正常小输入下，0 Step 不调用模型，1 Step 留给回答，2 Step 可选择 Skill 后回答，3 Step 可运行两次判断再回答。指定、禁用和空目录不消耗选择 Step；重试共用已取得的 Step，实耗不退。

运行详情的“本次输入”展示模式、所选顺序、加载/排除原因、来源/覆盖、正文 SHA-256 与码点数；真实 Attempt 另行列出实际携带。准备完成或 StepStarted 不证明发送。MainBar 仅在准备失败或降级时提示。Memory 页只读当前目录；旧 Run 正文只能来自当时中央脱敏的 trace，文件变化不能回填旧版本。追踪被裁剪或不完整时显示不可用，删除文件不会追溯擦除旧追踪。

聊天 Graph 的生产注入入口是 `RuntimeHost(chat_graph_factory=...)`。工厂接收已捕获的 `client/model/assistant/tools`，返回已编译且声明 `task` 输入的 Graph；可经 GraphRegistry 查找。父 Run 准备一次 Skill 和记忆窗口，Assistant 节点共享预算、来源证据、快照与绝对 deadline。纯分类节点不注入 Skill，提炼与 probe 也不启用选择器。此入口没有新增选图界面。

离线 ScriptedModel/本地传输测试证明输入与执行协议，不证明真实模型的语义选择或冲突识别质量。
